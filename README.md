**NovaMart E-Commerce Application**
Welcome to NovaMart! This is a full-featured e-commerce web application built as part of a project to showcase my skills in web development.

**Features**
**User Authentication:** Secure user registration and login.
**Product Catalog:** Browse and search for products.
**Shopping Cart:** Add and manage items in the cart.
**Checkout:** Integration with payment gateway for secure payments.
**Admin Dashboard:** Manage products, orders, and users.

**Technologies Used**
**Frontend:** HTML, CSS, JavaScript, React.js, Bootstrap
**Backend:** Node.js, Express.js, MongoDB
**API Testing:** Postman
**Deployment:** GitHub Pages
